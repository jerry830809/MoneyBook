# 專案需求文件（PRD）

## 專案名稱與代號

個人收支管理系統，代號 `moneybook`。

## 目標

記錄每天的收入與支出，了解每月賺多少、花多少，以及各類別花了多少。

## 使用者

只有我自己。

## 初步功能

- 記錄每一筆收入與支出。
- 查看每月明細及收入、支出統計。
- 查看各類別的支出。

## 專案規格

### 頁面與操作

| 頁面 | 功能 |
| --- | --- |
| `index.html` 月明細 | 顯示所選月份的總收入、總支出、結餘與逐筆明細。提供新增、編輯及單筆刪除入口。刪除前顯示交易名稱與金額，經確認後才刪除。 |
| `edit.html` 記帳 | 新增與編輯共用同一份表單。新紀錄的交易日期預設為臺灣當天，編輯時帶入原資料。儲存成功後回到該筆交易所在月份，取消則回到原先瀏覽的月份。 |
| `stats.html` 統計 | 顯示所選月份的支出分類圓餅圖，並列出各分類金額與占比。另以長條圖比較同月總收入與總支出。 |
| `settings.html` 設定 | 依 [Airtable 資料存取規範](Airtable.md) 輸入、儲存及清除 Token（權杖）與 Base ID（資料庫識別碼）。缺少任一設定時，資料頁先導向設定頁。 |

### Airtable 資料結構

收入與支出共用 `Transactions`（收支記錄）資料表。以 `Title` 為主欄位，編輯與刪除使用 Airtable 的原始記錄 ID。

| 欄位 | Airtable 型別 | 規則 |
| --- | --- | --- |
| `Title` | Single line text（單行文字） | 交易名稱，必填，去除首尾空白後須有內容。 |
| `Date` | Date（日期） | 交易日期，必填，以 `YYYY-MM-DD` 儲存，只記日期。 |
| `Type` | Single select（單選） | 必填。選項為「收入」「支出」。 |
| `Category` | Single select（單選） | 必填。選項限於所選收支類型的分類。 |
| `Amount` | Currency（貨幣） | 必填。新臺幣、零位小數，儲存大於零的整數。 |
| `PaymentMethod` | Single select（單選） | 必填。選項為「現金」「刷卡」「銀行轉帳」「行動支付」「其他」。 |
| `Note` | Single line text（單行文字） | 備註，選填。 |
| `CreatedAt` | Created time（建立時間） | 由 Airtable 自動填入，供同日排序使用。 |

- **收入分類**為薪資、獎金、兼職、投資收益、其他收入。
- **支出分類**為餐飲、交通、購物、居住、娛樂、醫療、教育、其他支出。
- 切換收支類型時清除已選分類，並更新可選清單。儲存前再次驗證分類與類型相符。

### 業務規則

- **月份**依臺灣時間預設為當月，可切上月、下月或直接選月。首頁與統計頁透過網址中的 `month=YYYY-MM` 沿用同一月份。月結依交易日期計算，範圍從當月第一天起至次月第一天前。
- **排序**按交易日期由新到舊，同日按建立時間由新到舊。
- **金額**依 `zh-TW` 顯示新臺幣與千分位，例如 `NT$1,250`。結餘為總收入減總支出，可以為負數，例如 `-NT$250`。介面用文字標明收入與支出，可輔以綠色與紅色辨識。
- **統計**使用所選月份的完整資料，包含分頁後的紀錄。圓餅圖只計入支出，占比為分類支出除以當月總支出。若當月沒有支出，顯示「本月無支出」而不繪製圓餅圖。長條圖仍顯示同月收入與支出，無紀錄的一方以零計。
- **操作失敗**時顯示繁體中文提示。儲存失敗保留表單內容，刪除失敗保留原明細。查詢失敗以錯誤狀態顯示，避免與無紀錄混淆。

### 驗收條件

- 可新增、編輯與刪除單筆交易。取消刪除時保留原紀錄。金額為零或小數、名稱只有空白，或類型與分類不符時，應阻止儲存。
- 驗證跨月切換、同日排序、首頁與統計頁月份一致，以及超過 100 筆時總額和圖表仍完整。
- 用同月收入 `NT$1,000`、餐飲支出 `NT$250`、交通支出 `NT$750` 驗證。首頁結餘應為 `NT$0`，圓餅圖應為 `25%` 與 `75%`，長條圖兩項均為 `NT$1,000`。
